# Guía del proyecto

Estos documentos son el mapa de **Entre líneas**. Se escribieron antes de construir los sistemas grandes para que cada decisión futura proteja la idea original: adquirir inglés leyendo historias, no completar ejercicios.

1. [Plan maestro](PLAN-MAESTRO.md): visión, experiencia y reglas que no se deben perder.
2. [Estructura futura](ESTRUCTURA-FUTURA.md): módulos, datos y límites entre partes del producto.
3. [Hoja de ruta](HOJA-DE-RUTA.md): orden recomendado de implementación y criterios para avanzar.
4. [Decisiones técnicas](DECISIONES-TECNICAS.md): lenguaje, framework, pruebas y por qué se eligieron.

## Cómo usar esta guía

Antes de añadir una función, revisa el plan maestro. Si hace que la app se sienta como una plataforma de ejercicios, no entra. Si afecta varios módulos, actualiza primero la estructura futura y luego implementa una fase pequeña de la hoja de ruta.
